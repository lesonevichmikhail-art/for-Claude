Автор: Михаил Лесоневич (нейродефектолог-логопед). Нейроигры и тренажёры по методу Лурии
(звенья A–H). Я (Claude) собираю игры по ТЗ Михаила. Михаил не программист, но умный: объяснять просто.

## Как работаем
1. Михаил кладёт ТЗ в `tz/` (или присылает в чат), материалы (PNG, звуки, голос) — в единую библиотеку `assets/library/` (любая ветка, любая беседа).
2. Перед игрой: прочитать `.claude/skills/dyadya-misha-obshchie-pravila/SKILL.md` (общие правила всех игр — основа, ТЗ игры перекрывает её только своими отличиями), ТЗ, `CLAUDE.md`, `ПАМЯТЬ_ПРОЕКТА.md`, скиллы `.claude/skills/rech-i-biblioteka` (речь в каждой игре, библиотека, выдача файлом) и `.claude/skills/igra-pod-klyuch` (как работать с Михаилом, скрипты, библиотека `assets/library/`), применить скиллы проекта
   (вход: `dyadya-misha-igra` для 5–8 лет, `kvest-vhod-9-18` для старших).
3. Возраст не указан — СПРОСИТЬ до генерации (скилл `adaptivnaya-podacha`).
4. Не хватает картинок/звуков — составить Михаилу список «что нужно» (с размерами и стилем). Пока PNG нет, в игре стоит серый прямоугольник с подписью имени файла (например `[mouse_jump.png]`), своих рисунков не делать.
5. Готовая игра: `games/drafts/` → после проверки по 5 вопросам (`proverka-igry`) → `games/final/`.
   **Цикл проверки (решение Михаила):** Михаилу отдаём только законченное. Перед выдачей — петля до чистого результата:
   (а) робот Playwright проходит игру целиком, портрет 390×844 и альбом 844×390: все экраны, ошибки, горизонтальный скролл, снимки;
   (б) независимый помощник-агент читает код по 5 вопросам и правилам проекта;
   (в) правим найденное → снова (а) и (б). Выход из цикла — только когда оба чистые. Итог — строка в `ПРОВЕРКА.md`.
6. В конце блока работы — дописать дельту в `ПАМЯТЬ_ПРОЕКТА.md` (решено / отказались).
7. Один шаг за раз для Михаила; параллелить можно только независимые задачи ИИ.

## Консилиум
Если механика игры (например, подъём уровня) расходится с профилем ребёнка (гиперактивный, низкий тонус), не решать молча: запустить консилиум (`case-consilium-luria`) и предложить Михаилу варианты. Цель для таких детей: успокоить, сосредоточить, увеличить удержание внимания, а не разогнать.

## Скиллы
Скиллы из подписки Михаила подтягиваются в эту среду сами (проверено: `dyadya-misha-igra` открывается целиком). Источник правды — скиллы аккаунта. Копии в `.claude/skills/` — только для того, чего в аккаунте ещё нет.

## Тропа вызова (во всех играх)
Автоподстройка остаётся всегда. Поверх неё ребёнок может по желанию подняться на один шаг выше («горная тропа»), с лимитами и страховкой. Детали: `.claude/skills/tropa-vyzova-poverh-skaffoldinga/SKILL.md`. Читать вместе с общими правилами при сборке любой игры.

## Подстройка трудности (по умолчанию, из общих правил)
2 ошибки подряд — появляется опора (подсветка, картинка-подсказка, замедление). 3 верных подряд — опора уходит, уровень +1. Трудность: по умолчанию «и так, и так» (игра сама + кнопка ребёнка картинками, без слов «легко/трудно»). В ТЗ игры можно смягчить или отключить подъём (например, для гиперактивных детей). Пороги не проверены на детях.

## Жёсткие правила игр (из ТЗ и промпта правки, Drive)
- Один HTML-файл, офлайн, двойной клик. Без CDN, внешних ссылок, шрифтов, аналитики, cookies.
- Графика — только свои PNG base64 (Flat Warm Vector, толстый контур, прозрачный фон). Без эмодзи, без нарисованного SVG, без стока.
- Звук — только WebAudio, планирование по `actx.currentTime`; TTS и микрофон запрещены. `AudioContext.resume()` на первом касании; звук можно выключить.
- События `pointerdown`, кнопки ≥ 60–64 px, шрифт ≥ 16–20 px, размеры от экрана (vw/vh), без горизонтального скролла.
- Ребёнок ДЕЛАЕТ, не читает: junior — одна короткая фраза. Всё умное — за кнопкой взрослого (`adultsSheet`).
- Ошибка мягкая: без красного, крестиков, грустных звуков, отката прогресса. Ни очков, ни процентов, ни рейтингов.
- Всё, что должно совпадать (дыхание: круг, картинка, персонаж) — меняется одной функцией; плавность через requestAnimationFrame, не CSS (prefers-reduced-motion гасит CSS).
- Контент отдельно от логики — объект `CONFIG`/`DATA` вверху файла. Каждый экран помечен звеном Лурии.
- Подпись «Дядя Миша» на заставке и в конце шпаргалки. Файл пишется целиком, без TODO и заглушек.
- Не обещать эффекта: «не замерено». Игра не заменяет телесную работу и постановку звуков.
