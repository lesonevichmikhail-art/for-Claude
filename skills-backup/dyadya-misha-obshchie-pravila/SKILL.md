# 00. Общие правила для всех игр — отдать кодеру ВМЕСТЕ с ТЗ игры

Проект «Дядя Миша». Развивающие HTML-игры по методу Лурии. Это файл-основа: в каждом ТЗ игры написано только то, что отличается.

## Формат
- Один автономный HTML-файл. Открывается офлайн одним кликом.
- Вся графика — PNG от Михаила, вшита base64. Никаких SVG-рисунков, эмодзи, стоковых картинок.
- Пока PNG нет — ставить серый прямоугольник-заглушку с подписью имени файла (например `[mouse_jump.png]`). Не рисовать своё.
- Звук — только WebAudio-синтез, мягкий. Кнопка выключения звука.
- Весь код выдать одним файлом целиком.

## Архитектура — маршрут Лурии (обязательно все 4 блока)
1. **Вход** — дыхание 3 цикла, герой здоровается.
2. **Восприятие** — показ/слушание материала, герой объясняет картинкой.
3. **Контроль** — ребёнок сам действует по правилу; самопроверка.
4. **Завершение** — спокойный финал, герой прощается, дыхание 1 цикл. Финал всегда на удаче.

Ядро движка (конечный автомат: `intro → breath → learn → play → check → finish`) — одно на все игры. Контент (слова, числа, герой) — отдельным объектом `CONTENT` в начале скрипта, чтобы менять без правки механики.

## Слои по возрасту (переключатель в окне взрослого)
| Слой | Возраст | Текст на экране ребёнка |
|---|---|---|
| baby | 5–6 | нет текста, только голос-звук и картинки |
| junior | 6–7 | 1 слово |
| senior | 8–10 | короткая фраза |
| teen | 11–14 | инструкция 1–2 строки, сюжет взрослее |

## Подстройка трудности (встроена)
- 2 ошибки подряд → опора появляется (подсветка, подсказка-картинка, замедление).
- 3 верных подряд → опора уходит, уровень +1.
- Кто выбирает трудность: по умолчанию «и так, и так» — игра сама + кнопка ребёнка картинками (1–4 цели, без слов «легко/трудно»). Режим меняется в окне взрослого.

## Запрещено
- Красные крестики, «неправильно», «проиграл», откат прогресса, таймер-давление.
- Горизонтальный скролл. Мелкие кнопки (минимум 64px).
- Застревание: из любого экрана есть пауза, рестарт, выход.

## Обязательно
- Пауза (и при сворачивании вкладки, и при открытом окне взрослого).
- Кнопка взрослого (ⓘ) → короткая шпаргалка: правило в одну строку / что тренирует / как помочь (3 пункта) / если трудно / сколько играть. Ниже — настройки: возраст, трудность, звук.
- Вписывается в экран телефона, портрет и альбом. Уважает reduce-motion (дыхание работает всё равно, мягче).
- Подпись «Дядя Миша» мелко слева вверху на заставке и в конце шпаргалки.

## Стиль графики (для всех промптов героев)
**Базовый хвост промпта — добавлять к каждому:**
> flat warm vector illustration, thick dark-brown outline, earthy warm palette (terracotta, ochre, olive green, cream, soft brown), rounded simple shapes, friendly calm expression, children's educational game asset, centered, full figure, transparent background, PNG, no text, no letters unless specified, no drop shadow

**Поправки по возрасту:**
- baby / junior: `very round shapes, big eyes, chubby proportions, cute`
- senior: `slightly more detailed, normal proportions, playful`
- teen: `stylized, less cute, cool confident look, graphic-novel flat style`

Размер: персонаж 1024×1024, предметы 512×512. Позы каждого героя — отдельными PNG.

## Готово — это когда
Прошли 4 блока; подстройка работает; ошибки мягкие; пауза/рестарт/выход везде; телефон без скролла вбок; звук выключается; шпаргалка короткая; автопроверка в Playwright пройдена.
