# Файлы в чат

Решение Михаила, 2026-09-30: «Мне всё должно быть видно здесь, в этом окне. В репозиторий я не хожу».

## Правило
1. Каждый файл, который создан или изменён для Михаила, отправить в чат инструментом отправки файлов (`SendUserFile`) сразу, как только он готов. Отправлять не пачкой в конце, а по мере готовности.
2. Игру (HTML) отправлять с показом прямо в окне (`display: render`).
3. Списки (что нужно: PNG, звуки), ТЗ, промпты — тоже отдельным файлом в чат. Короткий список дополнительно продублировать текстом в ответе, чтобы он был виден без открывания.
4. В ответе не писать «лежит в `tz/...`» вместо показа. Путь к файлу можно упомянуть только вдобавок к отправленному файлу.
5. Если файл менялся, отправить новую версию ещё раз.
6. Не отправлять служебное: черновые скрипты, тесты, промежуточные куски.
7. Пишем просто, без программистских слов: Михаил гуманитарий.

## Проверка перед концом ответа
- [ ] всё сделанное для Михаила отправлено в чат файлом
- [ ] списки «что нужно» видны прямо в тексте ответа
