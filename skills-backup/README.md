# Бэкап скиллов: что здесь и как вынести в аккаунт

Источник правды для скиллов — основной аккаунт Михаила (там лежат корневые). Они подтягиваются в рабочую среду сами. Папки здесь — черновики и копии того, чего в аккаунте ещё нет.

| Папка | Статус | Что сделать |
|---|---|---|
| `dyadya-misha-obshchie-pravila/` | нет в аккаунте | Загрузить как новый скилл, потом удалить копию здесь |
| `tropa-vyzova-poverh-skaffoldinga/` | нет в аккаунте | Загрузить как новый скилл, потом поправить три существующих (список в конце его SKILL.md) |

## Как вынести скилл в основной аккаунт (когда откроется подписка)
1. Открыть скилл `skill-creator`, попросить: «Создай скилл из этого файла» и приложить `SKILL.md` из нужной папки.
2. Проверить, что название и описание (frontmatter) сохранились.
3. Добавить новую строку в таблицу Шага 3 скилла `dyadya-misha-igra` (через `reviziya-skillov`).
4. Поправить расхождения: список в `ПАМЯТЬ_ПРОЕКТА.md`, раздел «Открытые вопросы».
5. В новой сессии проверить, что скилл виден здесь. Тогда удалить копию из `skills-backup/` и записать в `ПАМЯТЬ_ПРОЕКТА.md`.
