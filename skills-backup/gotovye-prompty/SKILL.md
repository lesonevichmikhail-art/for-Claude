# Готовые промпты

Решение Михаила, 2026-09-30: «Устал вырезать и вставлять техническую часть. Давай сразу готовые промпты».

## Правило
1. Один промпт = один блок кода (```), готовый к копированию целиком.
2. В каждый блок уже вписано всё: описание героя (одинаковое во всех позах), поза или предмет, стилевой хвост проекта, поправка по возрасту, размер, «transparent background, no text».
3. Нельзя писать «добавьте хвост из общих правил», «см. стиль выше», «+ базовый хвост».
4. Над блоком только имя файла, которое должно получиться (например `miki_jump.png`).
5. Если нужно больше одной картинки, сразу отдать все промпты одним файлом в чат (скилл `fayly-v-chat`), без отдельного списка «что нужно».
