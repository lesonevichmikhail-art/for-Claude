# Тропа вызова поверх автоподстройки

Решение Михаила, 2026-09-30: действует во ВСЕХ играх, не только в «Коне». Источник: консилиум (`research/КОНСИЛИУМ_такт_и_вызов.md`). Эффект не замерен, все числа — гипотезы для проверки на детях.

## Главное
- Автоподстройка остаётся ВСЕГДА, в обе стороны, под любым выбором ребёнка. Этот слой её не заменяет и не отключает.
- Тропа вызова — дополнительное приглашение: ребёнок по своей воле идёт на один шаг выше текущего авто-уровня. Так он переживает «я сам усложнил» и есть что показать маме или папе (мостик).
- Выбор ребёнка никогда не оценивается. Нет слов «легко/трудно», очков, серий, рейтингов.

## Два слоя
1. **Автоподстройка (всегда).** Держит ребёнка в рабочей зоне. Опора приходит и уходит тихо. По умолчанию: 2 ошибки подряд — опора; 3 верных подряд — опора уходит, уровень +1.
2. **Тропа вызова (по выбору ребёнка).**
   - Приглашение после 3 верных подряд, картинкой: «та же тропа» / «горная тропа» (имена и образы подстраиваются под сюжет игры).
   - «Горная» = текущий авто-уровень +1, только один шаг. Заход короткий (4–8 действий), потом возврат на основную тропу.
   - «Сложнее» = качество, а не скорость: дольше удерживать правило, меньше опор, убрать подсказку-якорь. Темп не ускорять.
   - Страховка: 2 промаха подряд в заходе — автоподстройка тихо возвращает на основную тропу, без «провала» и без слов. Успешный заход поднимает базовый уровень. Неудачный базовый уровень не снижает.

## Ограничители (экологичность)
- Предлагать только в состоянии регуляции: после успехов, без признаков усталости (растут промахи, замедляется реакция).
- Не чаще 1–2 раз за занятие. Не в последних действиях: финал всегда на удаче.
- Два неудачных захода за занятие — приглашения прекращаются до конца занятия.
- Оба ответа («та же» и «горная») подаются как хорошие. Любой выбор принимается.
- Без давления: если ребёнок три занятия подряд не выбирает вызов, шпаргалка предлагает взрослому «попробовать вместе».
- Специфика ребёнка решает ТЗ игры: например, для гиперактивного вызов = дольше держать такт, а не быстрее. При расхождении механики с профилем ребёнка — консилиум (`case-consilium-luria`) и варианты Михаилу.

## Мостик ко взрослому
- В финале виден значок выбранной тропы.
- Голос: «Покажи маме (папе, бабушке), какую тропу ты выбрал».
- В «трёх строках для взрослого»: «Спросите, почему выбрал горную» (или «почему остался на той же»).

## Режим в окне взрослого
«игра сама» (приглашения выключены) / «ребёнок выбирает» / «вместе». По умолчанию «и так, и так»: автоподстройка плюс приглашения. Ребёнок кнопок трудности с подписями не видит.

## В коде (объект DATA вверху файла)
```
challenge: {
  enabled: true,
  offerAfterCorrect: 3,      // верных подряд до приглашения
  stepUp: 1,                 // всегда 1
  burstLength: [4, 8],       // длина захода
  maxOffersPerSession: 2,
  stopAfterFailedBursts: 2,
  fallbackMisses: 2,         // промахов подряд для тихого возврата
  noOfferInLast: 2           // не предлагать в последних N действиях
}
```
Что именно усложняется (ядро вызова), пишет ТЗ игры: «меньше опор», «дольше удержание», «больше элементов». Ядро движка одно на все игры, меняется только этот блок.

## Проверка перед выдачей
- [ ] автоподстройка работает без тропы вызова и под ней
- [ ] приглашение картинкой, без слов «легко/трудно», оба ответа принимаются
- [ ] заход на один шаг выше, короткий, с тихим возвратом после 2 промахов
- [ ] лимиты соблюдаются, последние действия без приглашения, финал на удаче
- [ ] значок тропы и фраза-мостик в финале, строка для взрослого в шпаргалке
- [ ] режим «игра сама / ребёнок выбирает / вместе» переключается в окне взрослого
- [ ] все числа в DATA, а не в коде
