# Скиллы проекта

Лежат в репозитории и подхватываются автоматически в любой сессии на ветке, где они есть.

| Скилл | Что делает |
|---|---|
| `rech-i-biblioteka` | речь взрослого в каждой игре, единая библиотека, выдача файлом + «Не хватает» |
| `metodichka-igr` | методичка: карта и обоснование каждой игры, книга принципов, журнал обучения автора, сборка единой методички |
| `igra-pod-klyuch` | как работать с Михаилом, скрипты вшивания и нарезки, робот-проверяльщик |
| `dyadya-misha-obshchie-pravila` | общие правила всех игр (файл 00) |
| `tropa-vyzova-poverh-skaffoldinga` | автоподстройка + необязательная «горная тропа» по выбору ребёнка |

## Если скилл нужен и в основном аккаунте (десктоп)
1. Открыть `skill-creator` и приложить `SKILL.md` из нужной папки.
2. Проверить название и описание.
3. В `dyadya-misha-igra`, Шаг 3, добавить строки про новые скиллы (через `reviziya-skillov`).
4. Поправить `skaffolding-v-igre` и `dyadya-misha-igra`: убрать «кнопки трудности у ребёнка нет никогда», сослаться на тропу вызова.
