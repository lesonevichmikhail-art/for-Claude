# Речь взрослого, единая библиотека, выдача файлом

Решение Михаила 2026-09-30, действует во всех играх и во всех ветках. Консилиум по речи: `research/КОНСИЛИУМ_речь_в_играх.md`. Как работать с материалами и скриптами — скилл `igra-pod-klyuch`.

## 1. Три правила
1. **Ребёнок слышит живую речь взрослого в каждой игре.** Без речи нет развития. Голос всегда озвучен, подписи на экране зависят от слоя возраста.
2. **Всё берём из библиотеки `assets/library/`.** Картинки и голос, которые есть, вшиваем сразу. Чего нет — серая заглушка с именем файла и строка в «Не хватает». Михаил не останавливается: игра собирается и проходится целиком.
3. **Результат выдаётся файлом для скачивания** (`SendUserFile`, `display: attach`), а рядом документ `NE_HVATAET_<игра>.md`. Даже если недостающего нет, пишем «заглушек 0, голоса не хватает 0».

## 2. Речь взрослого
**Озвучено всегда, подписано по слою.**
| Слой | Голос | Подпись на экране ребёнка |
|---|---|---|
| junior (от 5, 4-летка тоже, до 8) | каждая инструкция | нет; подписи только у кнопок и предметов одним словом, если они нужны |
| senior (8–10) | каждая инструкция | первое предложение фразы, голос говорит всё |
| teen (11–14) | каждая инструкция | короткая инструкция 1–2 строки |

**Какие фразы (без когнитивного перегруза):**
- junior: 1–4 слова, до 2–3 секунд; senior: до 8–10 слов. Одна фраза = одно действие.
- Первым идёт глагол: «Слушай», «Топай вместе», «Стоим». Говорим позитивно: «у реки стоим», а не «не нажимай».
- Без оценки («молодец», «неправильно»). Описываем действие: «Конь пьёт», «Доехали».
- Речь звучит только в паузах: вход, смена правила, предложение тропы, финал, мостик. Поверх звуковых сигналов задания голоса нет.
- Не чаще одной фразы на экран. Две: на входе и в финале.
- Голос спокойный, медленный, без восклицаний (для гиперактивных и тревожных детей).

**Техника (образец: «Конь бежит по тайге» v3, движок E01):**
- Живой голос Михаила, mp3, вшиты в `const ZVUK` (base64). Синтез речи (TTS) запрещён.
- `const VOICE = { ключ: 'текст' }`. Ключ = имя mp3. Общие фразы `ob_*` берём из `assets/library/golos/obshchie`, фразы игры `<игра>_<ключ>` записывает Михаил.
- Нет mp3 → черновой режим: мягкий «дзынь» и полоска внизу «ключ.mp3 — «текст»». Игра проходится до конца, фразы идут в «Не хватает» и в `ZAPIS_<игра>.md`.
- На входе большая кнопка «Играть»: браузер молчит до первого касания.
- Кнопка «ухо» на экране с заданием повторяет последнюю фразу. Во время ритмичных сигналов она ничего не делает, голос не перебивает задание.
- Пауза и окно взрослого останавливают голос.

**Панель взрослого:**
- Отдельные переключатели: «Звук» (эффекты) и «Речь» (голос). Речь по умолчанию включена, выключить её может только взрослый.
- Каждый переключатель с крупной иконкой и словом. Тогда ребёнок, который ещё не читает, может сам найти «ухо» и разобраться: «Я могу как большой».
- Экран ребёнка не перегружаем: максимум 3 кнопки (главное действие, «ухо», «взрослому»). Всё остальное только в панели взрослого.

## 3. Единая библиотека
**Одно место: `assets/library/`.**
- `png/` — картинки. Имена `geroy_`, `predmet_`, `fon_`, `ikonka_`, латиница.
- `golos/obshchie/` — общие фразы для всех игр. `golos/slova/` — слоги и слова. `golos/<игра>/` — фразы игры.
- `KATALOG.md` — каталог: имя, что это, где используется. Имя файла = ключ в игре.
- Папки `assets/images/` и `assets/audio/` устарели. Новое туда не кладём.

**Правила:**
1. Михаил прислал PNG, mp3, m4a или ZIP в любом чате → сразу в библиотеку под стандартным именем + строка в `KATALOG.md`. Коммит и push в тот же ход.
2. Новая игра: сначала `node nedostayet.js` (или сверка с `KATALOG.md`), вшить всё, что есть, в список Михаилу только остаток.
3. Перед началом работы и после каждой порции ассетов: `git fetch origin`, подтянуть общую ветку, чтобы не разъезжались.
4. Все ветки и беседы работают от одной общей ветки. Сейчас общая ветка — та, где лежит эта библиотека (`git ls-remote origin HEAD`). Слияние веток в неё делает Claude по просьбе Михаила: только игры, ассеты, память, документы объединяются без потерь.
5. Файлы, которые у Михаила только на компьютере или в Drive, я не вижу: прошу прислать вложением (до 5 файлов за раз или один ZIP).

## 4. Выдача
В конце каждого шага:
1. Игра → `games/drafts/` (после проверки → `games/final/`), коммит, push.
2. Игра файлом `SendUserFile` (attach). Рядом `NE_HVATAET_<игра>.md`: картинки (имя → размер → промпт) и голос (ключ → текст). Если есть недостающий голос, ещё `ZAPIS_<игра>.md` (сценарий записи одним файлом).
3. В ответе коротко: что сделал → файлы → один следующий шаг.
4. Новые ассеты → `KATALOG.md`. Решения Михаила → `ПАМЯТЬ_ПРОЕКТА.md`. Урок → `research/УРОКИ_СБОРКИ.md`.

## 5. Чеклист перед выдачей
- [ ] каждая инструкция ребёнку озвучена (mp3 или черновой режим), речь в паузах, не поверх сигналов
- [ ] на экране ребёнка не больше 3 кнопок, подписи по слою
- [ ] в панели взрослого «Звук» и «Речь» отдельно, с иконками
- [ ] «ухо» повторяет последнюю фразу, вход с кнопкой «Играть»
- [ ] всё, что есть в библиотеке, вшито; остальное заглушки с именами
- [ ] `NE_HVATAET_<игра>.md` рядом с файлом игры
- [ ] новые PNG и mp3 лежат в `assets/library/` и записаны в `KATALOG.md`
