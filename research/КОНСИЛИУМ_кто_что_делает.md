# Консилиум: «Кто что делает?» (4–8 лет), 2026-09-30

Вопрос Михаила: закрепить «кто» и «что делает» рукой (кто — левая, что делает — правая, стучим мячик), чтобы потом легли подлежащее и сказуемое. Эффект не замерен, всё ниже — гипотезы.

| Кто | Что видит | Что заложено в игру |
|---|---|---|
| Логопед | Для 4–5 лет «что делает?» труднее «кто?»: глагольный словарь беднее. Вопрос задаём голосом, слово-действие — только на картинке. | Уровень 1 — только «кто?», уровень 2 — только «что делает?», уровень 3 — оба по порядку. |
| Нейропсихолог (III блок) | Порядок «сначала кто, потом что делает» — программа действия. Нажал действие раньше — это не ошибка, а сбой порядка. | «Сначала — кто?» без штрафа; счётчик «начал с действия» у взрослого. |
| Нейропсихолог (право-лево) | Лево/право у 4–6 лет ещё не устойчиво (складывается к 6–7 годам). Требовать «правильную руку» = ошибка и тревога. | Руку игра не проверяет. Левая рука = левый слот на экране = начало фразы (слева направо, как читаем). Взрослому: не поправлять, ставить свою левую рядом. |
| Кинезиолог | Движение разное по качеству: «кто» — подъём (статично, держим), «что делает» — удар мячом (ритм). Так тело различает два типа слова. | Две разные анимации и два разных звука (подъём / стук мяча). |
| Психолог | Для гиперактивных детей подъём уровня может разгонять. | В окне взрослого: «Подъём уровня — держать». Тогда рост — только по выбору ребёнка (горная тропа) и короткий заход. |
| Среда | Телесная часть без проверки — нужен взрослый рядом. | Экран «руки» между кругами + мостик: «Взрослый скажет — ты покажешь». |

Решить Михаилу: оставить ли «левая = кто» жёстко, или для левшей дать зеркальный режим в окне взрослого (пока не сделан).
