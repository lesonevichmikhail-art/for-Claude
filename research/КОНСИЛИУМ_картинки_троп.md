# Консилиум: картинки выбора тропы (2026-10-01)

Сравнивали для «ровной тропы»: **А** — луг с дубочками, холмы убраны (`ikonka_tropa_rovnaya.png`); **Б** — извилистая тропка с камнями, вид сверху (`originaly/tropa_rovnaya_variant_b.jpg`). «Горная» — новая, холм с флажком (`ikonka_tropa_gornaya.png`).

| Специалист | Мнение |
|---|---|
| Нейропсихолог | Сравнение должно идти по одному признаку: «ровно — круто». У А и горной один мир (деревья, цветы, вид сбоку), отличается только подъём. Б нарисована сверху, как карта: ребёнок сравнивает ракурс, а не трудность. → **А** |
| Логопед / речь | А легко назвать: «тропинка в лесу/на лугу», «тропинка на гору». Б называют «дорожка» или «змейка» — образ размыт. → **А** |
| Психолог | Флажок на вершине даёт цель: «трудно, но там хорошо» — вызов без угрозы. Обе тропы спокойные, тёплые, без страха высоты. → флажок оставить |
| Детский взгляд (5–6 лет) | У Б извилистость похожа на «трудную» тропу: можно спутать, где легко. У А дорожка прямая и широкая. → **А** |

**Итог:** ровная — А (с дубочками), горная — с флажком. Совпадает с выбором Михаила. Эффект не замерен; проверить на детях, понимают ли выбор без слов.
