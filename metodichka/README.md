# Методичка проекта «Дядя Миша»

Здесь методическое описание и обоснование каждой игры и общих принципов. Для обучения педагогов и передачи опыта, а также для самообразования автора. Правила ведения: скилл `.claude/skills/metodichka-igr`.

## Содержание
- `00_obshchie_principy.md` — книга принципов (почему игры устроены так).
- `igry/` — методическая карта каждой игры.
- `ZHURNAL_OBUCHENIYA.md` — что нового мы поняли (пополняется после каждого консилиума и решения).
- `TEMPLATE_karta_igry.md` — шаблон карты.
- `METODICHKA_sobrannaya.md` — единая собранная методичка (`python3 tools/sobrat_metodichku.py`).
- Полные консилиумы: `research/КОНСИЛИУМ_*.md`.
