# Сценарий записи: «Конь бежит по тайге»

Одним файлом m4a, Windows «Звукозапись» (не Телеграм). Медленно, спокойно, без восклицаний. 2 секунды тишины в начале и 2 секунды между строками. Ошиблись: молчите 5 секунд и скажите строку заново (слово «брак» не говорить). Присылайте файл латиницей в названии, например `kon.m4a`.

Порядок строк:
1. kon_topay — Топай вместе.
2. kon_reka — У реки тишина. Стоим.
3. kon_dyn — Услышал «динь» — прыгаем.
4. kon_naoborot — Теперь наоборот.
5. kon_vybor — Какую тропу выберешь?
6. kon_doehali — Доехали. Конь отдыхает.
7. kon_bridge_gornaya — Покажи маме, какую тропу ты выбрал.

Резку по паузам и вшивание в игру делаю я (`narezat.py`, `vshit_golos.py`). Проверить на слух вам.
