# Общая библиотека картинок (PNG_LIBRARY)

Все картинки проекта лежат здесь, для любых игр. Готовые к вшивке: 320×320, прозрачный фон, 128 цветов.
Исходники от Михаила: `originaly/` (как пришли, с шахматкой).
Подготовка: `tools/ubrat_shahmatku.py` → `tools/podgotovit_png.py`. Вшивка в игру: `tools/vshit_png.py <игра.html>` (берёт только те имена, что упомянуты в игре).

## Стандарт для всех игр: выбор «тропы вызова»
- `ikonka_tropa_rovnaya.png` — «та же тропа»: плоский луг, дорожка, деревья, холмов нет.
- `ikonka_tropa_gornaya.png` — «горная тропа»: крутой подъём в горы от уровня дубов, передний план убран.
Контраст «ровно / круто» читается без слов. Эти две картинки ставим на экран выбора в КАЖДОЙ игре (решение Михаила 2026-09-30).
